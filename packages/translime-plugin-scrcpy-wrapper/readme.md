# translime-plugin-scrcpy-wrapper

基于 scrcpy 与 adb 的 Android 设备投屏与独立应用虚拟屏窗口包装插件。

## 功能特性

- **整屏镜像**：
  - 无边框全透明悬浮窗口，配合外轮廓语义色边框与圆角。
  - 鼠标悬停立即显示背景卡片、自绘标题栏与快捷工具栏（返回、主页、最近应用、横竖屏切换、独立新窗口打开、息屏/亮屏），移出后延迟约 2 秒自动隐藏。
  - 画面框以自然流布局包裹 scrcpy SDL 实际矩形，四周仅保留紧凑留白，边距区域可拖动窗口。
  - 按设备实际宽高比等比缩放，自动持久化并恢复用户调整的窗口尺寸。
  - 画面 letterbox 底色启动时取宿主主题 outline 令牌，与外框边框同色贴合圆角；
    scrcpy 不支持运行中改背景色，主题变更后的新会话自动跟随。
  - 横竖屏切换通过锁定设备旋转方向实现，会话关闭时自动恢复锁定前的旋转设置；
    旋转后交换画面宽高适配窗口，视觉尺寸与旋转前大致相当。
- **独立虚拟屏**：
  - 针对指定应用启动独立虚拟屏幕窗口。
  - 自动启用应用全沉浸模式，隐藏系统导航条与状态栏。
  - 输入法直接在虚拟屏窗口内弹出，不弹在实体屏。
  - 音频采用 playback 音源独立采集，不劫持设备端播放，也不影响整屏镜像会话
    （要求 Android 13+，采集失败时自动降级为无声）。
  - 分辨率连续跟随窗口尺寸自适应拉伸，窗口拉伸尺寸按应用包名自动持久化并优先恢复。
  - 会话期间保持设备唤醒；关闭窗口时应用转回实体屏而不是退出。
- **设备管理与专属设置**：
  - 顶部按钮组单选已保存设备（支持 USB 有线与无线设备）。
  - 有线设备在配对弹窗中自动检测并支持一键添加；添加后拔掉仍留在列表中（标记离线），插上后自动恢复在线。
  - 支持按设备 ID 持久化配置视频码率（8M/16M/24M/32M）与最高帧率（30/60/90/120/不限），镜像与虚拟屏同时生效。
  - 支持无线调试 6 位配对码配对、端口扫描重连与已保存设备管理。
  - 跨窗口实时响应宿主主题色与明暗模式切换。
  - 应用包列表采用虚拟滚动渲染，数百个应用包不阻塞面板。

## 系统要求

- Windows 10/11 x64
- 设备端开启开发者选项与 USB / 无线调试
- 本机需安装 scrcpy 与 adb（可将路径加入系统 PATH，或在插件设置中指定 scrcpy 路径）
- scrcpy >= 5.0：整屏镜像依赖 `--render-fit=stretched` 与 `--no-window-aspect-ratio-lock`
  （帧铺满窗口、窗口比例由插件接管），独立虚拟屏依赖 `--new-display`、`--flex-display`、
  `--display-ime-policy`、`--audio-source=playback`、`--keep-active` 等沉浸参数集

## 插件配置项

- `scrcpyPath` (file): 自定义 `scrcpy.exe` 的完整路径。留空时默认使用系统 PATH 中的 `scrcpy`。

## 常用命令

```bash

pnpm dev

# 构建插件产物
pnpm build

# 运行单元测试
pnpm test

# 运行代码检查
pnpm lint
```

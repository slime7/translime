# translime-plugin-scrcpy-wrapper

基于 scrcpy 与 adb 的 Android 设备投屏与独立应用虚拟屏窗口包装插件。

## 功能特性

- **整屏镜像**：
  - 无边框全透明窗口，使用主题外轮廓边框与圆角。
  - 聚焦时悬停立即显示标题栏与快捷工具栏，失焦时悬停 1 秒后显示，鼠标移出后渐隐。
  - 窗口尺寸等比缩放并按设备记忆恢复。
  - 支持快捷导航（返回、主页、最近任务）、横竖屏切换、新窗口打开及屏幕开关。
- **独立虚拟屏**：
  - 针对指定应用启动独立虚拟屏幕窗口。
  - 隐藏系统导航条与状态栏。
  - 输入法在虚拟屏窗口内弹出。
  - 音频音源采用 playback 独立采集（需 Android 13+，不可用时降级为无声）。
  - 分辨率随窗口拉伸自适应调整，窗口尺寸与位置按应用包名记忆恢复并优先应用。
  - 会话关闭时自动将窗口焦点交还至整屏镜像窗口。
- **设备管理与参数配置**：
  - 设备以硬件序列号归一化管理，支持 USB 有线与无线设备。
  - 无线设备支持 mDNS 服务自动解析与端口变更重连。
  - 顶部按钮组单选已保存设备。
  - 管理弹窗支持添加在线 USB 设备、无线配对码配对及移除已保存设备。
  - 支持按设备持久化配置视频码率（8M/16M/24M/32M）与最高帧率（30/60/90/120/不限），镜像与虚拟屏同时生效。
  - 应用包列表支持关键字过滤与虚拟滚动。

## 系统要求

- Windows 10/11 x64
- Android 设备开启开发者选项与 USB 或无线调试
- 本机已安装 scrcpy 与 adb（需位于系统 PATH 或在插件设置中指定）
- scrcpy >= 5.0

## 插件配置项

- `scrcpyPath` (file): 自定义 `scrcpy.exe` 的完整路径。留空时默认使用系统 PATH 中的 `scrcpy`。

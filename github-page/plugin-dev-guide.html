translime 插件开发指南

面向在仓库之外开发 translime 插件的开发者：从安装宿主到发布插件。

一、准备

  • 安装 translime 宿主（Windows / Linux）。宿主是插件唯一的真实运行与调试环境。
  • Node.js ≥ 18.20 与 pnpm 10，用于构建插件包。
  • 在宿主 设置 中开启 显示开发中插件，插件中心会出现开发插件相关入口。

二、创建或引入插件

打开 插件中心 → 创建开发插件，两种方式：

  • 从模板创建：填写包名（translime-plugin- 前缀自动带上）、标题与描述，选择存放目录（留空默认放在宿主 plugins_dev 目录）。宿主会基于内置模板生成完整插件项目，并自动链接进开发插件列表。
  • 引入已有目录：选择一个已存在的插件项目目录（package.json 需含 plugin 字段）。宿主只建立链接，项目保留在原位置。

创建完成后插件出现在插件中心列表中，右键插件卡片可 启用、重启、打开插件目录。开发插件不发布 npm，仅在本机宿主中可见。

三、开发与调试

用编辑器打开插件目录（可在卡片右键选择「打开插件目录」）：

  • index.js 是主进程入口（声明生命周期钩子、IPC handler、命令），构建为 dist/index.cjs.js。
  • ui.vue 是内嵌 UI 入口，构建为 dist/ui.esm.js。
  • 运行 pnpm install && pnpm dev 同时监听两套构建；构建产物变化后，宿主会 自动重启该插件（需开启「显示开发中插件」），无需手动操作。
  • 手动刷新可用插件中心的 刷新开发中插件 按钮或卡片右键 重启插件。
  • 调试 UI：卡片右键可打开插件 webview 的 DevTools；调试主进程逻辑：宿主内置 日志查看器。
  • 断点调试主进程：宿主开发模式以 --inspect=5858 启动，VSCode 附加该端口即可在插件 index.js 中打断点（插件 pnpm dev 的 watch 构建自带 inline sourcemap）。
  • 独立窗口插件可在 manifest 中声明 windowUrl.dev 指向本地 dev server，获得热更新。
推荐先用 preview:ui 在浏览器中快速调整界面，但布局、主题与宿主集成行为一律以宿主内实际效果为准。

四、SDK 与 manifest

插件通过 translime-sdk 访问宿主能力，API 与环境边界见 SDK 文档。常用约定：

建议在 package.json 中加一行 "$schema": "https://slime7.github.io/translime/translime-plugin.schema.json"，编辑器即可对 manifest 字段做补全与校验（从模板创建的插件已默认包含）。

约定说明
包名必须以 translime-plugin- 开头，小写字母、数字、连字符
激活时机plugin.activationEvents：带 UI 的工具插件建议 onView，后台插件才用 onStartup / onAppReady
宿主兼容engines.translime（semver），缺省视为兼容
IPC 命名事件名@插件ID，例如 ipc.invoke('get-data@translime-plugin-demo')
样式隔离使用 SDK 的 createPluginCssIsolationPlugins(pluginId)，宿主运行时自动加 @scope 与 layer
图标Material Design Icons（md）风格，禁止 mdi- 前缀

五、发布

  • 确认 package.json：去掉 private、files 包含 dist 与图标、main 指向 dist/index.cjs.js、版本号递增。
  • pnpm build 后建议先在宿主中完整验证一轮。
  • npm publish 发布到 npm；宿主通过 npm registry 检索与安装插件包。
  • 发布后可用分享链接 https://slime7.github.io/translime/open/?install=你的插件包名 让用户一键跳转安装。
